# CrossTCN 动态时间锚点实验

## 方法与对照

固定10个query，采用可学习归一化中心与宽度。两组实验共享5/3/2分组的均匀中心，区别仅为宽度初值：uniform全部为0.12；multiscale为5个0.04、3个0.12和2个0.32。几何正余弦编码经MLP映射后加入原query位置向量。

decoder逐层预测logit空间的区间残差，并将本层区间detach作为下一层参考锚点；共享span头末层零初始化。保持CrossTCN、Hungarian匹配、分类/L1/GIoU/saliency与辅助层监督，以及原Top-3导出。不使用前景监督、困难负样本、旧多尺度卷积、TRCC、Bridge或IoU-rank。

## 训练协议

- 两配置各使用42、2026、3407三个种子，共六次训练。
- 每次90 epoch，batch 32，AdamW学习率0.00015，weight decay 0.0001；StepLR第67轮后乘0.1，每5轮评估dev。
- 对照为CrossTCN相同预算结果12.59/12.04/12.08，均值12.236667、样本标准差0.306649。
- 主要验收：至少两个种子提升，三种子平均增益至少0.30个百分点。短区间覆盖与预测长度诊断作为后续结果分析，不以单种子最好成绩代替主结论。

## 执行与恢复

远端仓库为`/data1/xz/repos/QVHighlights`。独立调度器为`student_code/scripts/local/run_anchors.py`，结果根目录为`outputs/anchors_20261122`。

调度器对同一输出根目录加锁，两次间隔10秒确认GPU无计算进程、显存低于512MiB且利用率低于10%后派发，每卡最多一个任务。空闲磁盘不足10GiB停止派发，不足8GiB停止本队列。单次训练超时5400秒时停止该任务并保留产物。

每轮原子保存`model_last.pt`，包含模型、优化器、StepLR、Python/NumPy/Torch/CUDA随机流、DataLoader生成器、最佳模型与日志。重启调度器时跳过已完成实验；未完成实验在新attempt目录恢复最近完整epoch，配置、数据哈希与预算不一致时拒绝恢复。中断发生在epoch中间时仅重跑该epoch，旧attempt保留。
