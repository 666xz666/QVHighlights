# 稠密前景与局部空隙监督

以Cross+TCN、90轮、学习率1.5e-4、batch 32为对照，种子42/2026/3407，StepLR第67轮衰减。现有对照dev mAP为12.59/12.04/12.08，均值12.24，样本标准差0.31。

编码器视频memory接独立256→1线性前景头，初始化隔离随机数，不改变已有模块初值。前景头不参与候选评分；原saliency监督、10个query与Top-3导出保持不变。损失梯度流入编码器。

完整train标注构造2秒clip中心上的GT并集，不使用max_windows截断后的匹配标签。BCE先按正负类各自求均值，再类间和query间平均。全前景、全背景或无适用空隙均有定义，padding不参与损失。

局部项先合并重叠/相接GT区间，再取相邻连通区间之间的背景空隙。相邻连通区间宽度不超过10秒者为短片段，分别计算softplus(0.2 + 空隙均值logit - 短片段均值logit)，左右片段、空隙、适用query逐级等权。该定义不包含被其他区间覆盖的伪空隙，也不把合并后的长连通区域当成短片段。

固定两组消融，各三种子：

- cross_tcn_fg：原损失 + 0.1 × BCE。
- cross_tcn_fg_gap：原损失 + 0.1 × BCE + 0.03 × 局部项。

以三种子均值及同种子差值比较，预设至少2/3种子改善且平均增益至少0.30 pp。新增权重为首轮固定设定，尚无收益保证；短片段覆盖、空隙分离与中长片段表现用于诊断，不替代正式mAP。

冒烟验证包括真实两样本两步更新、完整模型初始化预测一致、backbone梯度、完整GT/padding梯度方向、模型和optimizer恢复后下一步逐参数完全一致。不修改baseline文件或正式checkpoint。

一次性调度脚本位于被git忽略的student_code/scripts/local/，只使用连续两次确认空闲的GPU，每卡一个任务；失败保留attempt，重启跳过完成项，未完成项重新训练而非epoch级续训。磁盘低于10GiB不派发、低于8GiB停止自身任务，单任务上限5400秒。
